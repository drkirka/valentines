# valentines
# Valentine Interactive Vision Web App 💘

Small interactive browser project using webcam face tracking, hand gestures, and animated UI effects.

---

## Features

- Webcam face and hand tracking
- Smile detection
- Finger counting and gesture recognition
- Animated UI effects
- Floating emojis and confetti
- Heart-shaped camera overlay
- Snapshot effect for thumbs down interaction
- Simple multi-scene interaction flow

---

## Technologies Used

- HTML
- CSS
- JavaScript
- MediaPipe Hands
- MediaPipe FaceMesh
- Canvas API

## How to Run

Open the project with Live Server or run a local server.

Example:

```bash
python3 -m http.server 5500
```

Then open the local browser link and allow camera access.
